# Gestion de Compétition Sportive — Python

Application console développée en Python permettant de gérer une compétition sportive de bout en bout.

## Fonctionnalités
- Gestion des équipes, joueurs et postes
- Planification et suivi des matchs
- Gestion des phases de compétition
- Persistance des données via SQLite
- Authentification par mot de passe

## Technologies
- Python 3
- SQLite3
- Architecture orientée objet (POO)

## Structure du projet
| Fichier | Rôle |
|---|---|
| `main.py` | Point d'entrée |
| `competition.py` | Classe principale |
| `equipe.py` / `joueur.py` | Entités |
| `match.py` / `phase.py` | Logique de jeu |
| `DB_app_console_CAN_Ketsia.py` | Couche base de données |

## Lancement
```bash
python main.py
```
